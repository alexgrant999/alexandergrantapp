WHY THE LAST ONE FAILED, SO THIS ONE DOES NOT
================================================================================
1. The old description argued that opt-in did not apply ("There is no public
   opt-in form because website visitors are never messaged"). A reviewer looking
   for a consent mechanism reads that as "no consent mechanism". The new copy
   describes an actual opt-in: the caller rings us, is asked, and says yes on a
   recorded line.

2. Opt-in keywords and opt-in message were blank while the opt-out message said
   "Reply START to resubscribe". START is therefore already an opt-in keyword
   and has to be declared. That inconsistency is the kind of thing reviewers
   catch.

3. Sample messages carried markdown list numbering ("1. Hi Gregory..."). Samples
   are compared against real traffic, so the numbering had to go.

4. Embedded links was not ticked despite sample #1 containing three URLs.

5. The help message had no sender identity. Carriers expect the brand name.
